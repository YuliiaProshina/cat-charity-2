# QRKot — благотворительный фонд поддержки котиков

QRKot — API-сервис для благотворительного фонда.  
Сервис позволяет создавать благотворительные проекты, принимать пожертвования и автоматически распределять поступившие средства между открытыми проектами.

## Возможности

- создание благотворительных проектов;
- просмотр списка проектов;
- частичное редактирование открытых проектов;
- удаление проектов, в которые ещё не были внесены средства;
- создание пожертвований;
- просмотр списка пожертвований;
- автоматическое распределение пожертвований между проектами;
- автоматическое закрытие полностью профинансированных проектов и пожертвований.

## Технологии

- Python
- FastAPI
- SQLAlchemy
- Alembic
- Pydantic
- SQLite

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/YuliiaProshina/cat-charity-1.git
cd cat-charity-1
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

Активировать окружение:

```bash
source venv/Scripts/activate
```

### 3. Установить зависимости

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Применить миграции

```bash
alembic upgrade head
```

Проверить текущую миграцию:

```bash
alembic current
```

### 5. Запустить приложение

```bash
uvicorn app.main:app --reload
```

После запуска документация API доступна по адресу:

- Swagger: `http://127.0.0.1:8000/docs`

## Основные эндпоинты

### Благотворительные проекты

| Метод | Адрес | Описание |
|---|---|---|
| `GET` | `/charity_project/` | Получить список всех проектов |
| `POST` | `/charity_project/` | Создать новый проект |
| `PATCH` | `/charity_project/{project_id}` | Частично изменить проект |
| `DELETE` | `/charity_project/{project_id}` | Удалить проект |

### Пожертвования

| Метод | Адрес | Описание |
|---|---|---|
| `GET` | `/donation/` | Получить список всех пожертвований |
| `POST` | `/donation/` | Создать новое пожертвование |

## Примеры запросов

### Создание проекта

```json
{
  "name": "Лечение",
  "description": "Сбор средств на лечение кота",
  "full_amount": 5000
}
```

### Создание пожертвования

```json
{
  "full_amount": 3500,
  "comment": "На помощь котику"
}
```

Поле `comment` необязательное:

```json
{
  "full_amount": 500
}
```
